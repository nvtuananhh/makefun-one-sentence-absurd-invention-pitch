## What it does

`main.py` (Python 3, standard library only, no network) writes
one sentence to `/output/entry.txt` — a pitch for a ridiculous
invention that fixes a tiny everyday annoyance:

> My doorbell files a formal noise complaint against anyone who rings it twice, and it has already sued the postman three times.

The sentence is 126 characters long. The invention turns the
tables: the doorbell punishes the ringer instead of announcing
them, and it has already escalated to suing the postman three
times. One sentence, one twist at the end.

## How to run

```sh
python3 main.py
```

## Output

Writes one sentence (126 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
